# B3 handoff — domain endpoints + idempotency

## Module map (routes thin; every write ONE atomic batch, revision bump last)
- `api/_lib/idempotency.ts` — `requireIdempotencyKey` (422), `bodyHashOf` (sha256 key+route+canonical body), `findReceipt` (48 h TTL reads expired as absent), `replayOf` (changed body → 422 `idempotency_key`); receipt+sweep ride the effect's batch.
- `api/_lib/domain.ts` — `DomainError`, RBAC read-outs (`mayCloseRun`, `isDeliveryAgent`), stmt builders (guarded upsert+assert, insert-once, counter belt, audits), `errorBody`; `formatSeries`/`stockIdFor`/`isGradedUnit`/`gradeMath` inlined (see deviations).
- `api/_lib/closeRun.ts` + `api/transformations/close.ts` — B2 guards as authority when `batch_v2` on (spoilage ≥1, server-recomputed balance; flag-off closes legacy-style), spoilage records+ledger draw, Closed + `stageTimes.closed` + stockIds minted, audit, CAS 409.
- `api/_lib/gradingPost.ts` + `api/grading.ts` — `pipeline` gate (421), coconut-only (422 `not_gradable`), grade sum vs load, server-side cost math, paired `Grading` transfer lines, `already_graded` guard.
- `api/_lib/dispatchConfirm.ts` + `api/dispatch/confirm.ts` — FEFO over Released rows, planDeduction cartons (LOOSE never writes carton lines), challan+dispatch counters, reservations, Partially Dispatched/Dispatched, coldRoomOutAt.
- `src/lib/genealogy.ts` (pure fold+BFS) + `api/_lib/traceSearch.ts` + `api/genealogy.ts`, `api/search.ts` — edges folded from grns/batches/packing_runs/orders/dispatches/shipments; search LIKE-escaped per kind, max 5, withholding honored.
- Tests: `api/_lib/b3.test.ts` (56) + `b3Routes.test.ts` (10). Gates: `tsc -b` clean; 935 passed.

## Deviations/gaps (contracts untouched)
1. `DispatchConfirmResponse` + `challan` (additive) — contracts predate returning the challan.
2. PO numbers unsearchable: frozen `SEARCH_KINDS` has no `po` kind.
3. `numbering`/`grn`/`stockIds` inlined into `domain.ts` — those src/lib modules aren't api-compilable (extensionless imports).
4. Grading keeps `gradingMode: 'staged'` (GRADING_MODES has no 'graded'); grades-on-document = graded, `already_graded` refuses re-grade.
5. Close spoilage draws only from same-uom output rows; extraction-stage losses with no matching row are record-only.
6. `rulesGate.batchLines` exported for close.
