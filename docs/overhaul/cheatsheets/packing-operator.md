# Cheat sheet — Packing operator

*Applies when the new look (Pipeline) is switched on. Your pages: Packing (+ Production's
packing form).*

## Open first
**Pipeline** → the Packing tile counts runs posted **today** (an activity tile — a packing
run posts complete, nothing stays open).

## Your loop
1. **Run a packing** — Production → *Run a packing* (the register's *Run packing* opens the
   same form): pick the bulk (its batch counts show beside it), then one line per pack —
   glass bottles or **loose BIB pouches** (1L / 2.5L / 5L).
2. **Check materials before you save** — the materials preview is the same walk the save
   gate runs: bottles, caps, labels, pouches, with shortfall flags. Fix the store, not the
   number.
3. **Keep control samples on the run** — how many bottles, from which line, produced day.
   Samples are never stock; they only owe a destruction date later (QC's shelf).
4. **BIB rule** — pouches are stored **loose** in the cold room; the pouch is the tracked
   unit. Cartons are decided at **dispatch**, never at packing.

## Words to know
- **Bulk** = what you pack from. A retired pack stays offered only so the empty state can
  explain itself.
- Two packs with the same label are named apart in the dropdown — pick carefully.
- QC's verdict applies to the whole batch (bulk and packs drawn from it).

## Gotchas
- A scanned BAT id finds its batch under any fillable bulk and switches the bulk for you.
- The register shows every run ever posted — filter by day, not by scroll.
