# Cheat sheet — Production operator

*Applies when the new look (Pipeline) is switched on. Your pages: Production (runs).*

## Open first
**Pipeline** → the Extraction and Blending tiles list runs still open. A run leaves the
tile when it is **closed** — spoilage recorded, balance stamped.

## Your loop
1. **Run a pressing** — Production → *Run a pressing*: pick the graded lot (or scan it),
   outputs are pre-filled (water main, malai by-product), counts confirmed not typed.
   Mandatory: spoiled-at-press count + reason. The **mass-balance bar** must close.
2. **Run a blend** — Production → *Run a blend*: pick the recipe; one draw row per
   component appears in recipe order; scan or pick each lot. Blend losses are recorded at
   close, not on the run.
3. **Run packing** — Production → *Run a packing*: pick the bulk, then pack lines (bottles
   or loose BIB pouches), materials preview shows shortfalls before you save. A packing
   run posts **complete** — there is no close step.
4. **Close what you opened** — an open run's row on the board links straight back to its
   close form (only the spoilage is asked).

## Words to know
- **Bulk** = blended product waiting to be packed. **Malai** = the coconut by-product that
  becomes coconut milk (a blend run with a milk recipe).
- **Close** = record spoilage + confirm the balance. An unclosed run stays on the board.
- Quarantined bulk **can** be drawn for a blend; press-only raw cannot (the app refuses).

## Gotchas
- Every run gets a QC record per output — QC releases or holds it, not you.
- Control samples are recorded on the packing run, never moved as stock.
