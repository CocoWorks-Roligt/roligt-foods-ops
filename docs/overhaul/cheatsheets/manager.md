# Cheat sheet — Manager

*Applies when the new look (Pipeline) is switched on. Your pages: everything you hold —
commonly the board, dashboards, traceability, audit.*

## Open first
**Pipeline** — the whole plant as one board: every stage, what waits in it, and the
bottleneck sentences (stuck over the 2-day mark, holds, near-expiry intermediates, orders
past ship-by). Counts match the sidebar badges by construction — one number, everywhere.

## Reading the plant
1. **Bottlenecks first** — the board leads with the flagged stages; the note is the
   sentence to ask about ("Oldest run open 4 days", "3 lots on hold").
2. **Any lot's story** — click a run → Batch Detail: honest timeline, forward/backward
   genealogy (coconut → pressing → malai → milk → blend → pack), and the ONE next action
   with who owes it. Refused actions show their reason in plain words.
3. **Numbers** — Live Reports (labelled **Dashboards**): live figures with a freshness
   stamp; if a screen is stale it says so.
4. **Who changed what** — Audit Log: every write, old value → new.

## Words to know
- A stage's count is **waiting work** (grading owed, runs open, verdicts pending) or
  **today's activity** (receipts, packing runs) — the tile says which.
- **Blend** is the app's word for every mixed run (smoothies and shakes too).
- Spoilage is mandatory on close — a run cannot vanish quietly.

## Gotchas
- The 2-day "stuck" mark is a config value (Settings) — tune it to the plant's rhythm
  before treating every flag as a fire.
- Page ticks on a role carry that page's **writes** — tick deliberately (see Roles &
  Permissions).
